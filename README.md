# BuyNow Cart Service

## Overview

The Cart Service allows customers to add products to their shopping cart, manage quantities, and calculate the total cart value.

## Features

- Add to Cart
- Remove Items
- Update Quantity
- Cart Total Calculation
- Product Service Integration

## Tech Stack

- Java 21
- Spring Boot
- OpenFeign
- Spring Data JPA

## APIs

- Add Cart Item
- Remove Cart Item
- Clear Cart
- Get Cart
